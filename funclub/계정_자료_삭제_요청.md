# 계정·자료 삭제 요청

펀클럽(`com.develogic.funclub`)에서 만든 계정과 자료를 지우는 방법입니다.
구글 플레이가 요구하는 **웹에서 낼 수 있는 삭제 요청 창구**이기도 합니다.

## 먼저: 앱 안에서 바로 지울 수 있습니다

메일을 기다리지 않아도 됩니다. 앱 안에 길이 있고, 누르는 즉시 지워집니다.

| 지우려는 것 | 어디서 |
|-------------|--------|
| 내 임원 계정 | 앱 → 설정(톱니) → **임원과 함께 쓰기** → '클럽에서 나가기'. 내 임원 문서와 알림 주소가 지워집니다 |
| 회원 한 명 | 회원관리에서 그 회원을 삭제 |
| **클럽 자료 전부** | 총무가 앱 → 설정(톱니) → **임원과 함께 쓰기** → **'클럽 자료 통째로 지우기'**. 서버의 회원 명부·회비·대회·공지와 임원 계정이 모두 지워집니다 |
| 이 폰 안의 자료 | 앱을 지우거나, 안드로이드 설정 → 앱 정보 → 저장공간 → 데이터 삭제 |

> 서버 자료를 지워도 **그 폰 안에 있는 자료는 남습니다.** 폰 자료까지 없애려면
> 위 마지막 줄을 함께 하십시오.

## 메일로 요청하기

총무가 아니어서 위 길을 쓸 수 없거나, 앱을 이미 지워 눌러 볼 수 없을 때 씁니다.

**받는 곳: thedeveljun@gmail.com**

메일에 아래를 적어 주십시오.

1. 제목에 `삭제 요청`
2. 로그인에 쓰신 **구글 계정 이메일 주소** — 이것으로 어느 자료인지 찾습니다
3. 무엇을 지울지 — 내 임원 계정만인지, 클럽 자료 전부인지
4. 클럽 이름 (아시는 경우)

## 무엇이 지워지고, 무엇이 남나

| 지워지는 것 | 남는 것 |
|-------------|---------|
| 구글 계정 식별자(uid)·이메일 주소·계정 표시 이름 | 요청하신 분의 폰 안에 있는 자료 (직접 지우셔야 합니다) |
| 알림 주소(FCM 토큰) | 다른 클럽의 자료 |
| 요청하신 범위의 클럽 자료 — 회원 명부·회비·대회·공지 | |

**클럽 자료 전부를 지우는 요청은 그 클럽의 총무만 낼 수 있습니다.** 임원 한 사람의
요청으로 다른 사람들이 함께 보던 명부가 사라지면 안 되기 때문입니다.

## 언제까지 처리하나

받은 날부터 **7일** 안에 처리하고, 끝나면 답장을 드립니다.

지운 자료는 되돌릴 수 없습니다. 백업이 필요하시면 지우기 전에 앱의
설정(톱니) → **전체 백업** 으로 파일을 먼저 받아 두십시오.
